
Start of lesson:
- Have learners create a new 3D project called 'Object Oriented AI'
- Go to Project Settings > Player > Active Input Handling and set it to 'Both' 

Add a plane to the scene, scale it up 5x, attach a NavMesh Surface, set object collection to "Current Object Hierarchy" and bake.

Add a capsule to the scene which will be our player.

CHALLENGE: Create a DEAD SIMPLE player controller script
- Flat, transform-based movement in world space
- No jumping, no gravity
- No camera stuff
- 5 minutes

Show the PlayerMove script. "It can be that simple when we're just testing stuff."

Create a Prefab and build the template NPC. We're adding a little "face" to help us see where it's looking.

At this stage learners should be familiar with OOP principles from the OOP class.

Discuss how last week we made a variety of strategies, but we found ourselves having to rewrite a lot of similar code between them
- We can use OOP principles to make more reusable code
- Today we will be using a lot of Inheritance
    - this will naturally lead us to using Encapsulation, Abstraction, and Polymorphism

Write and demonstrate the scripts in turn, using the player as the target, and creating a prefab variant for each:
- HasTarget (no demonstration)
    - discuss that this script by itself doesn't do anything, it's just a basis
    - we'll talk about abstract next week so just plant the seed today
- FollowTarget
    - make a prefab variant with a nav agent
    - Stopping Distance of 2-3 will fix player clipping
- FollowTargetInRange

Divert here to make the NPC template with separate head.

Continue with the scripts:
- LookTowardsTarget
- LookTowardsTargetConstrained

CHALLENGE: Inherit from 'LookTowardsTargetConstrained' and make a new script (10 mins)
- Give the looking behaviour a maximum range
- If not in range, use the initial direction instead
- Leverage our existing IsTargetInRage function, and look at FollowTargetInRange for help
- Don't overcomplicate!

Then write the solution together.

Discuss how this approach of extending behaviour is one benefit to Inheritance.
- Now we'll make a few scripts which will demonstrate the real power of Polymorphism

Create the Interaction script, then the Interact script

In the scene:
- Place a rigidbody on the Player, turn off gravity, and tick all Constraints.
- Add a sphere collider trigger child object to the player, and attach the Interact script
- Add the Interaction component to any NPC

Demonstrate this working. Discuss a sphere collider is imprecise and can't tell what direction the player is facing.
- A full game could use a trigger which is just in front of the player
- Alternatively you could raycast forward from the player
- In first person you'd just raycast from the centre of the camera

Now write the 'InteractToFollow' script together. Attach it to the FollowTargetInRange NPC from earlier.

Demonstrate the NPC will follow the player on and off when interacting with them in range.

Encourage the learners to try writing their own 'Interaction', for an NPC or something else. Some suggestions are:
- Jump up and down or spin around
- Move to a new location
- Show a dialogue box
Or for a non-NPC:
- Collect an item
- Open a door or chest
- Pull a lever to trigger something else
